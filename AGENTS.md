# Portfolio design

For UI and UX work in this project, apply the local skills:
- `.agents/skills/frontend-design/SKILL.md` for visual direction and implementation.
- `.agents/skills/web-design-guidelines/SKILL.md` for accessibility and interaction review.

The user's design priorities are a calm, readable personal portfolio that conveys enthusiasm for building games. Keep the introduction and interactive planet distinct from the work, About, and Contact content below. The planet is the main visual feature; keep surrounding controls quiet. Preserve theme preferences, reduced motion, keyboard and touch access, saved game progress, and existing project links. Honor the user's current instructions over skill defaults.

Validate changed flows in the browser at desktop and phone sizes, in light and dark themes. Build with `npm run build`; existing smoke scripts accept `TOWN_URL`.
