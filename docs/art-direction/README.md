## Audit evidence and limits

The repository contains **no standalone `.blend`, `.glb`, `.gltf`, `.fbx`, `.obj`, `.mtl`, `.stl`, `.ply`, `.dae`, `.usd`, `.usdz`, `.usdc`, `.abc`, or `.3ds` files** outside dependencies/build output. The 16 bundled Idle Wizard ZIP directories also contain no files with these model extensions. The active town loads no external model library: its geometry is generated by TypeScript factories. The inventory therefore identifies source factory, family, component, and runtime instance rather than inventing model filenames.

The obsolete `world.js`/`world.css` village uses DOM/SVG. The two illustrated backdrops and five project artworks are raster assets, not 3D assets. The separately shipped `idle-whitch-craft/` app and Idle Wizard OTA distributions are preserved public products, not assets loaded into this town. Their bundles were checked for standalone model files; their internal gameplay is outside this redesign.

Code inspection covers every active geometry-producing module, the dormant `createLand()` builder, materials, growth stages, mergers, navigation, collisions, lighting, weather, and character props. An executable geometry census covers every plot at every reachable asset stage, plus the mature scene's structures, roads, walls, terrain, vegetation, residents, and contact shadows.

- [Desktop geometry census](geometry-audit-desktop.json)
- [Mobile geometry census](geometry-audit-mobile.json)
- Regenerate with `node --import tsx scripts/audit-town-assets.mjs` and the same command plus `--mobile`.
- Each report includes SHA-256 source hashes. The workspace was changing during inspection; compare hashes before production and rerun when inputs change.
- The script exposes the existing building factory in an in-memory transpiled copy. It does not edit source, instantiate WebGL, or change saves.
- Geometry counts include instantiated geometry even when a part is scaled nearly to zero. They exclude camera culling and GPU shadow passes. They are not FPS measurements.

At 50 minutes, seed 12345, the audited desktop structures contain 451,717 triangles; roads 53,300; walls 2,304; environment 294,318; town decor 28,880; residents 152,016; contact shadows 19,360. Mobile equivalents are 133,225 / 9,620 / 2,304 / 136,472 / 26,080 / 14,808 / 11,008. These measurements expose where to reallocate detail before expanding the library.

A browser smoke check opened `?age=30&profile`, dismissed the introduction, and found no captured warning/error logs. One early sample reported 119 render calls, 966,783 rendered triangles, frame p50 16.7 ms / p90 17.0 ms at pixel ratio 0.90. This sample predates subsequent external lighting edits and is not an acceptance benchmark. Browser screenshot capture failed, so **current artistic quality ratings are source-derived and provisional**. No render is being represented as visually approved.

Baseline `npm run check`: TypeScript and all 12 existing tests passed. This verifies existing logic, not artistic fidelity.

## Production dependency

The brief explicitly requires Blender MCP for modeling, inspection, and review. There is no callable Blender tool in this session, and the plugin-directory search for Blender returned no plugin. No Blender file, Blender render, export, agent production, or artistic approval has been claimed. The requested production workflow question remains pending: connect Blender MCP, or explicitly permit adapting the existing procedural factories.

The plans and assignments are ready for execution once that dependency is resolved. Pre-production is complete; the full environment redesign is **not complete**.
